# 🧟 ZOMBIE MOUNTAIN: 3D WebGL FPS Survival

Three.js 기반의 1인칭 3D 좀비 서바이벌 웹 게임입니다.  
인트로 화면에서 전장과 난이도를 선택한 뒤, 다양한 무기와 스킬을 활용해 몰려오는 좀비 웨이브를 막아내세요.

## 🔗 플레이 링크
- **인트로 시작:** `https://jodongyoung.github.io/zombie-game/home.html`

---

## 🗺️ 전장 (Maps)
1. **좀비 산장 (`mountain`)** — 침엽수림과 바위산 봉우리가 어우러진 산악 생존 전장
2. **유령 도시 (`city`)** — 어두운 밤하늘과 고층 빌딩, 깜빡이는 가로등과 폐차가 있는 도심 전장
3. **사막 유적 (`desert`)** — 붉은 황혼 아래 거대 피라미드와 고대 석주, 선인장이 있는 사막 전장

---

## 🎯 난이도 & 라운드 규칙
- **쉬움:** 최대 **20라운드** (5라운드마다 대량 웨이브 러시 경고)
- **보통:** 최대 **30라운드** (5라운드마다 대량 러시 + 체력 10배 초대형 보스 등장)
- **어려움:** 최대 **40라운드** (5라운드마다 진화형 초대형 보스 등장 및 라운드 진행에 따른 이동/투사체 템포 상승)

---

## 🔫 무기고 (`[N]` 키) & 슬롯 구성
- **`[1] 주무기`:** AK-47, M4A1, SPAS-12 샷건, AWP 스나이퍼(우클릭 줌), 팜 레이저, 컴파운드 활(탄창 무제한)
- **`[2] 보조무기`:** Glock 권총, 데저트 이글, 샷건 권총, 기관권총(UZI)
- **`[3] 근접무기`:** 전투 도끼(앞으로 찍기), 긴 마체테(가로 횡베기), 카타나(2연속 X자 베기 + 검기)
- **`[4] 투척/중화기`:** 수류탄, 바주카포(10발 제한 · 무기고 재교체 시 리필)

---

## 🎮 조작법
- **이동 / 2단 점프:** `W A S D` / `Space` (2번)
- **공격 / 저격 줌 / 장전:** `좌클릭` / `우클릭` (스나이퍼) / `R`
- **궁극기 (공중 강하 충격파):** `V` (쿨타임 30초)
- **무기고 / 설정창:** `N` / `ESC` (효과음 ON/OFF, 마우스 민감도, 인트로 복귀)

---

## 🛠️ 사용 기술 스택
- **Rendering:** Three.js (WebGL)
- **Frontend:** HTML5, CSS3, JavaScript (ES Modules)
- **Audio:** Three.js Audio & Web Audio API
